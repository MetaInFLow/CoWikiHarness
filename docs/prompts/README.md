# Agent Operating Prompts

This project uses repository instructions instead of storing product runtime prompts at the bootstrap stage.

Before work: read `AGENTS.md`, `CONSTITUTION.md` and `docs/memory-bank/active-context.md`.

Before a pull request: verify the active design, run `pnpm verify`, run `git diff --check` and update active context.

Runtime prompts will be added only when the P0 Agent journey defines their input, output schema and evaluation baseline.
