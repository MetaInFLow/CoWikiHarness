# ADR 0002: External Component Version Policy

- Status: Accepted
- Date: 2026-07-18

## Decision

External components are exact-pinned in the lockfile and accepted through contract tests. Phase 0 validates QMD 2.5.3, llm-wiki-compiler 1.1.0, and the stable Codex app-server schema generated by the installed CLI. A version upgrade must pass the same contract suite before release.

## Rules

- Use public SDK, CLI, or MCP contracts first.
- A compatibility adapter may depend on a pinned implementation detail only when an ADR identifies the detail, failure behavior, upstream path, and removal condition.
- No component is silently substituted when missing or incompatible.
- License notices remain attributable in release artifacts.
