# Project Constitution

These are product red lines.

1. Never scan a directory or platform without explicit Source authorization.
2. Never copy third-party project source into this repository; install official releases and call public interfaces.
3. Never access QMD private storage, private SQLite tables or internal APIs.
4. Never copy or store Agent credentials in openLifeWiki configuration, Wiki, logs or command arguments.
5. Never mark a lifecycle stage complete before its executable acceptance checks pass.
6. Never write long-term Wiki changes without human approval of the exact proposal.
7. Never persist a partial successful state after a failed installation or initialization.
8. Never delete the confirmed Wiki during default uninstall.
9. Never add a later-stage dependency to initialization for convenience.
10. Never merge generated output, runtime data, logs or personal Source content into Git.
